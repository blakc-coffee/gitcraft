# GitCraft planning pack

Proposed v0.1 · Research began 2 November 2026; planning review completed 3 November 2026. This pack records the planning stage. A local two-exercise prototype now exists; see the [project README](../../README.md) for current implementation and limits.

Recommended direction: **a browser-first Git diagnosis and recovery lab, with short placement for two learner groups and an independent real-Git task at graduation.** Test two exercises before expanding to eight missions. Multiple collaborator workspaces are a teaching aid; better independent performance is the value to prove.
